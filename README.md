# Pose Atelier · 动作与机位参考

用于插画构图、动作和透视研究的本地浏览器工具。可以在参考图片上直接拖动关键点，调整体块比例与遮挡；也可以切换三维人偶，独立调整摄影机并实时预览。

默认进入「参考图对齐」工作台。图片在浏览器本机处理，无需账号或后端服务；依赖安装并构建完成后，运行无需联网。

## 功能

- **参考图对齐**：导入图片、拖动 18 个关键点、区分可定位与推测位置。
- **动作修改**：二维两段肢链跟随、固定关键点、方向键微调。
- **体块编辑**：调整头、胸腔、骨盆和四肢的宽高、倾斜、粗细及遮挡顺序。
- **三维机位**：19 个受限关节、独立观察与取景相机、焦距和画幅调整。
- **保存与导出**：浏览器自动保存、JSON 项目恢复、长边 2048 像素 PNG。
- 撤销 / 重做、图层透明度、镜像及预设起点。

## 快速开始

需要 **Node.js 22.12 或以上**及其自带的 npm。首次安装依赖需要联网。

```sh
git clone https://github.com/deepdarkdemon621-dev/pose-atelier.git
cd pose-atelier
```

### Windows

双击仓库根目录的 `Start-Pose-Studio.cmd`。脚本会在需要时安装依赖、构建应用并打开浏览器。保持命令窗口打开，关闭窗口或按 Ctrl+C 停止服务。

也可以在项目目录执行：

```sh
node scripts/launch.mjs
```

### 手动运行 / macOS / Linux

```sh
npm ci
npm run build
npm start
```

打开终端输出的地址，默认是 [http://127.0.0.1:4173](http://127.0.0.1:4173)。Windows 启动器会自动打开浏览器，其他平台请手动打开该地址。

服务只监听 `127.0.0.1`。4173 端口占用时会尝试至 4193，请以终端输出为准。仓库不包含 `node_modules` 和 `dist`，首次使用时由启动器生成。

## 参考图对齐

1. 默认载入内置插画与手工设置的关键点起点，也可以点击「导入图片」或直接拖入 JPG / PNG / WebP（15 MB 以内）。新图片以通用站姿起点开始，需要手动对齐。
2. 「对齐原图」：直接拖动关键点，让头、躯干、肘膝、手脚对齐原图。允许画面长度、比例和局部透视夸张。
3. 「修改动作」：拖手腕或脚踝时，二维两段肢链跟随，尽量保留屏幕中的肢段长度；拖躯干会带动相连部位。拖肘膝可调整弯曲方向。
4. 选中关键点后点击「固定此点」，后续拖动优先保持该点不动。固定点与长度要求冲突时，优先保持固定点，因此肢段可能伸缩。
5. 使用「局部体块」调整头、胸腔、骨盆等的宽高与倾斜，调整四肢粗细、显隐及遮挡顺序。肢段的长短由关键点间距决定。
6. 右侧「干净体块预览」实时显示导出效果。「包含底图」决定预览与 PNG 是否保留参考图片；导出长边 2048 像素。

画布：拖空白平移，滚轮缩放，「适应画布」复位。方向键微调选中的点，Shift + 方向键移动 10 像素。支持 Ctrl+Z / Ctrl+Y 撤销重做。

黄色关键点与虚线表示遮挡或画外推测，可自行移动或修改标记。示例中的上肢大多遮挡或在画外，相关体块初始隐藏，可以在局部体块设置中开启。手工起点不是自动识别结果。

项目自动保存在当前本地地址的浏览器 IndexedDB。「保存项目」下载包含原图、关键点、固定状态与体块参数的 JSON，「打开项目」可在其他浏览器或本地端口恢复。

参考图工作台采用二维投影体块，允许局部比例夸张，不把屏幕里的关节夹角当作真实人体角度。它暂不自动重建三维姿势，也不与三维机位工作台互相转换。

## 三维机位使用

- 点击人偶体块或右侧关节按钮选中部位，拖动彩色旋转环。也可以使用角度滑条或数值框。X / Y / Z 为关节局部轴。
- 左键拖动空白区域旋转观察，右键拖动平移，滚轮缩放。上方观察相机与下方取景相机独立。
- 「相机设置」调整水平环绕、俯仰、拍摄距离、焦距、倾斜和注视目标。亦可点击「使用当前视角」把观察机位应用至取景相机。
- 支持画幅切换、动作起点、镜像姿势、关节及全身复位、撤销 / 重做（Ctrl+Z / Ctrl+Y）。
- 编辑内容自动保存在当前浏览器的当前本地地址下。「保存场景」下载 JSON，「打开」恢复 JSON。切换浏览器或端口不会共享自动保存数据。
- 「导出参考图」生成长边 2048 像素 PNG。导出使用下方画幅，包含地面光影，不含选中高亮、旋转环、摄影机和网格。

## 关节范围与限制

角度为绘画用近似活动范围。以关节局部坐标和几何体朝向定义，不能直接当成临床关节角。

| 关节 | 范围（度） |
| --- | --- |
| 肩 | 前举 170，后伸 45，外展 170，内外旋 75 |
| 肘 | 屈曲 0–145；其余轴锁定 |
| 前臂 | 旋前 / 旋后各 80 |
| 腕 | 屈伸各 65；侧偏约 20–30 |
| 髋 | 前屈 120，后伸 25，外展 45，内收 20；内外旋约 40–45 |
| 膝 | 屈曲 0–140；其余轴锁定 |
| 踝 | 跖屈 40，背屈 20，内外翻各 15 |
| 骨盆、腰、胸、颈、头 | 分段设置较小范围，叠加表达整体姿势 |

肩、髋等多轴关节使用椭圆形组合范围，避免每个轴同时达到极值；拖动某轴到极限时其他轴可能收敛。左右对应关节使用镜像范围。

三维模式尚未实现身体碰撞检测、重心平衡、IK、脚部自动贴地或手指关节。肢体仍可能穿过身体，需结合预览手动调整。全身站位固定，骨盆可旋转。二维模式的手脚连动是屏幕空间两段链求解，与三维 IK 相互独立。

## 开发与验证

技术栈：React 19、TypeScript、Three.js、Vite；二维编辑使用 SVG，自动保存使用 IndexedDB。

```sh
npm ci
npm run dev
```

打开 Vite 输出的本地地址。其他命令：

| 命令 | 用途 |
| --- | --- |
| `npm test` | 运行 16 项关节、二维肢链和数据验证测试 |
| `npm run build` | TypeScript 检查与生产构建 |
| `npm start` | 运行本地生产构建 |

测试使用 Node.js 的 TypeScript 类型剥离功能；部分 Node.js 22 版本会输出 experimental 提示。

## 项目结构

```text
src/
  main.tsx                工作台切换与三维界面
  ReferenceApp.tsx         参考图工作台与 SVG 体块
  reference-model.ts      二维关键点、肢链求解与项目校验
  reference-storage.ts    IndexedDB 自动保存与图片嵌入
  rig.ts                 三维素体、关节与父子关系
  limits.mjs             三维关节角度约束
  studio.ts              三维场景、相机、历史与图片导出
public/                  图标与内置示例图
scripts/                 本地启动与 HTTP 服务
tests/                   核心行为测试
Start-Pose-Studio.cmd     Windows 启动入口
```

内置示例图用于演示参考图工作流，关键点起始位置为手工设置，并非自动识别结果。
